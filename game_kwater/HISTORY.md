## 📋 프로젝트 개요

K-Water 마스코트 '방울이'를 이용한 친환경 물 절약 캠페인 게임 이벤트 페이지입니다.
- **게임 타입**: 2D 횡스크롤 플랫포머
- **플랫폼**: 모바일 웹 (반응형)
- **비율**: 9:16 (모바일 최적화)

## 🔧 주요 기술 구현

### 게임 엔진
- Canvas API 기반 2D 렌더링
- RequestAnimationFrame으로 60FPS 게임 루프
- 물리 시뮬레이션 (중력 0.6, 최대 낙하속도 15)

### 입력 처리
- 터치 이벤트 (touchstart, touchmove, touchend)
- 마우스 이벤트 (mousedown, mousemove, mouseup)
- 키보드 이벤트 (키보드 입력)
- 조이스틱 위치 계산 및 정규화

### 충돌 감지
- AABB (Axis-Aligned Bounding Box) 충돌 감지
- 플랫폼 착지 판정
- 물방울 수집 판정 (거리 기반)

### 그래픽 렌더링
- 배경 이미지 전체 화면 표시
- 발판 이미지 직접 렌더링
- 캐릭터 이미지 방향 반전 (scale(-1, 1))
- 물방울 이미지 + 글로우 효과

### 음향 시스템
- Web Audio API 활용
- 자동 재생 실패 처리 (모바일)
- 볼륨 개별 조절


### 중력 & 물리
```javascript
- 중력: 0.6
- 최대 낙하속도: 15px/프레임
```

### 플랫폼
```javascript
- 바닥: canvas.width × 50px
- 발판 1~5: 각 150×20px
- 배치: 다양한 높이와 좌우 위치
```

### 물방울
```javascript
- 개수: 4개
- 반지름: 15px
- 글로우 효과: 사인파로 애니메이션
```

## 🚀 배포 방법

### 1. 로컬 테스트
```bash
cd 2d_kwater
python -m http.server 8000
# 또는
npx http-server
# 브라우저에서 http://localhost:8000 접근
```

### 2. 웹사이트 통합
- 전체 폴더를 웹사이트 레포에 복사
- 상대 경로로 모든 링크 설정되어 있음
- 어디에 배치해도 동작

### 3. 직접 링크 방식
```html
<!-- 웹사이트에서 게임 연결 -->
```

## 💡 개발 시 주의사항

- `game.js`: 플레이어 속도, 중력, 점프력 등 게임 상수 변경 가능

### 음향 교체 시
- 파일명을 동일하게 유지
- assets 폴더에 동일 위치에 배치
- 형식: MP3 (bgm), WAV (효과음)

### 성능 최적화
- 이미지 파일 크기 최소화
