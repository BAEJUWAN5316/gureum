# 에셋 추가 가이드

이 프로젝트에서 필요한 그래픽과 음악 에셋을 추가하기 위한 가이드입니다.

## 필요한 그래픽 에셋

### 1. 로고 이미지
- **파일명:** `assets/logo.png`
- **크기:** 60x60px (메인 페이지, 종료 페이지)
- **설명:** K-Water 로고

### 2. 캐릭터 일러스트
- **위치:** 메인 페이지의 placeholder로 현재는 텍스트 "방울이"로 표시됨
- **권장 크기:** 200x200px
- **설명:** K-Water의 마스코트 '방울이' (물방울 형태의 귀여운 캐릭터)

## 필요한 음향 에셋

### 1. 배경음악
- **파일명:** `assets/bgm.mp3` (또는 `.wav`, `.ogg`)
- **길이:** 루프 가능한 배경음악
- **톤:** 밝고 청량한 분위기

### 2. 점프 사운드
- **파일명:** `assets/jump.mp3`
- **길이:** 약 0.3초~0.5초
- **톤:** 경쾌한 점프 효과음

### 3. 물방울 수집 사운드
- **파일명:** `assets/collect.mp3`
- **길이:** 약 0.3초~0.5초
- **톤:** 반짝이는 듯한 수집 효과음

### 4. 게임 클리어 사운드
- **파일명:** `assets/clear.mp3`
- **길이:** 약 1초~2초
- **톤:** 축하하는 듯한 승리 팡파레

## 에셋 추가 방법

1. `assets/` 폴더에 이미지 또는 음향 파일을 넣습니다.
2. HTML/JS 파일에서 다음과 같이 참조합니다:

### 이미지 추가 예시
```html
<img src="assets/logo.png" alt="K-Water 로고" class="logo">
```

### 음향 추가 예시 (game.js)
```javascript
// 배경음악
const bgmAudio = new Audio('assets/bgm.mp3');
bgmAudio.loop = true;
bgmAudio.volume = 0.5;
bgmAudio.play();

// 효과음
const jumpSound = new Audio('assets/jump.mp3');
jumpSound.play();
```

## 추가 주의사항

- 파일명은 정확히 일치해야 합니다.
- 이미지 형식: PNG, JPG, WebP 권장
- 음향 형식: MP3, WAV, OGG 권장
- 모바일 호환성을 위해 파일 크기를 최적화하세요.

## 그래픽 스타일 가이드

- **색감:** 밝고 청량한 색상톤 (하늘색, 연한 파랑, 흰색 중심)
- **스타일:** 캐주얼 2D 아트 (만화/일러스트 스타일)
- **해상도:** 주요 그래픽 1024x1024px (고해상도 디바이스 대응)
