# K-Water 게임 연계 이벤트 페이지

K-Water의 브랜드 인지도 및 친밀도 제고를 위한 인터랙티브 게임형 이벤트 페이지입니다.

## 프로젝트 개요

- **목표:** 마스코트 '방울이'를 활용한 친환경·물 절약 캠페인형 게임
- **플랫폼:** 모바일 웹 (반응형 디자인, 9:16 비율 최적화)
- **게임 타입:** 2D 횡스크롤 플랫포머

## 파일 구조

```
2d_kwater/
├── index.html           # 메인 HTML 파일 (5개 페이지 포함)
├── styles.css           # 전체 스타일시트 (반응형 디자인)
├── game.js              # 게임 로직 (물리, 충돌 감지, 렌더링)
├── plan.md              # 원본 기획서
├── README.md            # 이 파일
├── ASSETS_README.md     # 에셋 추가 가이드
└── assets/              # 그래픽/음악 리소스 폴더 (추후 추가)
    ├── logo.png         # K-Water 로고
    ├── bgm.mp3          # 배경음악
    ├── jump.mp3         # 점프 효과음
    ├── collect.mp3      # 물방울 수집 효과음
    └── clear.mp3        # 게임 클리어 효과음
```

## 페이지 구조

### 1. 이벤트 메인 페이지 (E1)
- K-Water 로고 및 제목 표시
- 방울이 일러스트
- "게임 시작하기" 버튼

### 2. 게임 페이지 (G1)
- Canvas 기반 2D 횡스크롤 게임
- 플레이어 캐릭터 (현재 간단한 원형)
- 플랫폼 및 물방울 아이템
- 모바일 조이스틱 (좌/우 이동) + 점프 버튼
- 물방울 수집 UI

### 3. 클리어 페이지 (C1)
- 축하 메시지 및 애니메이션
- "이모티콘 받기" 버튼

### 4. 개인정보 입력 페이지 (F1)
- 이름 입력창
- 전화번호 입력창
- 개인정보 수집 동의 체크박스
- "제출하기" 버튼

### 5. 이벤트 종료 페이지 (E2)
- 감사 메시지
- K-Water 로고
- SNS 공유 버튼 (카카오톡, 트위터, 페이스북)
- "메인으로 돌아가기" 버튼

## 게임 플레이

### 조작법
- **좌/우 이동:** 화면 하단 좌/우 버튼 또는 화살표 키 (A/D)
- **점프:** 화면 하단 점프 버튼 또는 스페이스바 (W)

### 목표
- 모든 물방울 4개를 수집하여 게임 클리어
- 플랫폼을 넘어다니며 물방울을 찾기

## 기술 스택

| 항목 | 사용 기술 |
|------|---------|
| 프론트엔드 | HTML5, CSS3, JavaScript |
| 게임 엔진 | Canvas API (바닐라 JS) |
| 반응형 | CSS media query (모바일 최적화) |
| 데이터 처리 | 로컬 콘솔 출력 (DB 저장 없음) |

## 시작하기

### 1. 파일 생성
프로젝트 폴더에 다음 파일들이 준비되어 있습니다:
- `index.html`
- `styles.css`
- `game.js`

### 2. 웹 브라우저에서 실행
```bash
# 로컬 웹 서버로 실행 (권장)
python -m http.server 8000
# 또는
npx http-server

# 그 후 브라우저에서 열기: http://localhost:8000
```

또는 `index.html`을 직접 브라우저에서 열어도 됩니다.

### 3. 에셋 추가 (선택)
`ASSETS_README.md` 파일을 참조하여 그래픽과 음악을 추가합니다.

## 개발 팁

### 게임 로직 수정
`game.js` 파일에서 다음을 수정할 수 있습니다:
- `player` 객체: 캐릭터 크기, 속도, 점프력
- `physics` 객체: 중력, 마찰, 최대 낙하 속도
- `createPlatforms()`: 플랫폼 배치 변경
- `createDrops()`: 물방울 위치 변경
- `drawPlayer()`: 캐릭터 그래픽 커스터마이징

### 스타일 수정
`styles.css` 파일에서 색상, 크기, 폰트 등을 수정할 수 있습니다.

### 페이지 추가/수정
`index.html`에서 새로운 페이지를 추가하고 `game.js`의 네비게이션 함수로 연결할 수 있습니다.

## 주의사항

- 그래픽과 음악 에셋은 포함되어 있지 않습니다. `ASSETS_README.md`를 참조하여 추가하세요.
- 개인정보 입력 데이터는 DB에 저장되지 않고 콘솔에만 출력됩니다. (테스트 목적)
- 모바일 환경에서 최적의 경험을 위해 세로 방향(portrait)으로 사용하세요.
