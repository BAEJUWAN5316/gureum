# K-Water 게임 연계 이벤트 페이지 기획서

---

## 1. 프로젝트 개요
**프로젝트명:** K-Water 게임 연계 이벤트 페이지  
**목표:** K-Water의 브랜드 인지도 및 친밀도 제고를 위한 인터랙티브 게임형 이벤트 페이지 제작

**주요 목적:**
- 브랜드의 마스코트 '방울이'를 활용한 친환경·물 절약 캠페인형 게임 제작
- 이벤트 참여를 통한 사용자 데이터(이름, 전화번호) 수집
- 모바일 친화적인 UX/UI로 접근성 강화

---

## 2. 전체 흐름 구조 (User Flow)

1. **이벤트 페이지 접속**  
   - K-Water 공식 채널 또는 광고를 통해 이벤트 웹페이지로 유입
   - 페이지 상단에 이벤트 소개 및 참여 유도 문구 표시
   - [게임하기] 버튼 클릭 시 게임 페이지로 이동

2. **게임 페이지**  
   - '방울이' 캐릭터 조작을 통해 물방울 4개를 수집하는 횡스크롤 게임
   - 조작 방식: 모바일 조이스틱(좌/우 이동) + 점프 버튼 1개
   - 모바일 최적화 화면 비율(세로형 비율 기준, 9:16 비율 대응)
   - 주요 그래픽 리소스 해상도: 1024x1024px
   - 배경음 및 효과음 포함

3. **클리어 페이지**  
   - 물방울 4개 수집 시 클리어 메시지 표시
   - "축하합니다! 이모티콘을 받을 수 있습니다." 문구 출력
   - [이모티콘 받기] 버튼 클릭 시 개인정보 입력 페이지로 이동

4. **정보 입력 페이지**  
   - 입력 항목: 이름, 전화번호, 개인정보 수집 동의 체크박스
   - 테스트 페이지이므로 DB 저장은 비활성화
   - '제출' 버튼 클릭 시 이벤트 종료 페이지로 이동
   - 이벤트 종료 페이지에는 K-Water 로고 및 SNS 공유 버튼 배치

## 3. 주요 구성 요소

### 3.1 UI/UX 설계
| 구분 | 구성 요소 | 설명 |
|------|-------------|------|
| 메인 페이지 | 게임 소개, 게임 시작 버튼 | 단순하고 직관적인 디자인, 상단에 방울이 일러스트 배치 |
| 게임 화면 | 캐릭터, 플랫폼, 아이템, 배경 | 2D 횡스크롤 방식, 밝고 청량한 색감 유지 |
| 클리어 화면 | 클리어 텍스트, 버튼 | 성취감을 주는 애니메이션 효과 포함 |
| 정보 입력 페이지 | 이름/전화번호 입력창, 체크박스 | 모바일 터치 최적화된 입력창 |

### 3.2 조작 시스템
- **좌/우 이동:** 터치식 모바일 조이스틱
- **점프:** 화면 우측 하단 점프 버튼
- **게임 클리어 조건:** 물방울 4개 수집 시 클리어 트리거 발동

### 3.3 그래픽 사양
- **주요 그래픽 사이즈:** 1024x1024px
- **스타일:** 캐주얼 2D 아트, 밝은 색상톤(하늘색, 연한 파랑, 흰색 중심)
- **캐릭터:** 방울이 (물방울 형태의 귀여운 마스코트)
- **배경:** 하늘 + 수면 + 구름 + 건물 실루엣

### 3.4 사운드
- 배경음악
- 캐릭터 점프 시 사운드
- 물방울 획득 시 사운드
- 게임 클리어 시 사운드

## 4. 기술 구성

| 항목 | 사용 기술 | 설명 |
|-------|-------------|------|
| **프론트엔드** | HTML5, CSS3, JavaScript | 기본 구조 및 게임 UI 구축 |
| **게임 엔진** | Vibe Coding (엔진 기반) | 캐릭터 이동, 충돌 판정, 아이템 수집 로직 구현 |
| **반응형 구조** | CSS media query | 모바일 환경 대응 (9:16 비율 중심) |
| **데이터 처리** | JavaScript 모의 데이터 처리 | 개인정보 입력 시 DB 연결 없이 콘솔 출력 처리 |

---

## 5. 페이지 구성도

```plaintext
[E1] 이벤트 메인 페이지
 └▶ [G1] 게임 페이지 (횡스크롤 플레이)
     └▶ [C1] 클리어 페이지 (이모티콘 받기 버튼)
         └▶ [F1] 개인정보 입력 페이지
             └▶ [E2] 이벤트 종료 페이지
```

---

## 6. 화면 예시 (Wireframe)

**[E1] 이벤트 메인 페이지**
- 상단: K-Water 로고, 제목 “방울이의 물방울 찾기 이벤트!”
- 중앙: 방울이 일러스트 + “게임 시작하기” 버튼

**[G1] 게임 페이지**
- 하단: 조이스틱 (좌/우) + 점프 버튼
- 중앙: 방울이 캐릭터, 플랫폼, 물방울 아이템 4개

**[C1] 클리어 페이지**
- 중앙 텍스트: “축하합니다! 방울이가 모든 물방울을 찾았습니다.”
- 하단 버튼: “이모티콘 받기” → 개인정보 페이지로 이동

**[F1] 개인정보 입력 페이지**
- 입력창 2개: 이름, 전화번호
- 체크박스: 개인정보 동의
- 제출 버튼: “제출하기”
